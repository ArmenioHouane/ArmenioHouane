## Sobre mim

Sou um desenvolvedor focado na criação de aplicações web modernas, acessíveis e fáceis de manter. Trabalho principalmente com o ecossistema JavaScript/TypeScript, React e Next.js, sem deixar de explorar Python e C# para backend, automação e soluções complementares.

- Desenvolvo interfaces responsivas e experiências digitais centradas no utilizador.

- Gosto de transformar problemas reais em produtos simples, rápidos e bem estruturados.

- Valorizo código limpo, boas práticas, aprendizagem contínua e colaboração.

- Atualmente, estou aberto a projetos interessantes, networking e oportunidades de colaboração.
